# SmaltCode v0.0.8 · 智能体底层全面升级与 Windows / macOS 双端打包

**Windows x64 + macOS 13+ (`arm64` / `x64`) 公开测试版。** 欢迎体验并通过 [GitHub Issues](https://github.com/lryoooow/SmaltCode/issues) 反馈问题与建议。

## 本次更新亮点

### 1. 模型网关、前缀缓存与推理深度控制（`U1`, `U7`, `U12b`）

- **OpenAI `/v1/responses` 原生协议支持**：新增 `ResponsesAdapter` 流式适配器，解锁 `gpt-5.3-codex`、`gpt-6.1-sol` 等推理编码模型的原生文本、推理摘要、函数调用及缓存用量统计。
- **跨模型 Prefix Cache 命中优化**：Anthropic 自动在系统提示词末尾、工具列表末尾及最新历史轮次注入 `cache_control: { type: "ephemeral" }`；OpenAI / DeepSeek 自动注入会话级 `prompt_cache_key`，并在跨轮请求中剥离历史 `reasoning_content`（保留当前轮工具链思维），避免推理输出污染前缀缓存；底栏实时显示前缀缓存命中比例。
- **可控思考深度（Reasoning Effort）**：输入框工具栏支持为推理模型切换 `low` / `medium` / `high` / `max` 思考预算（CLI 支持 `/effort`）。

### 2. 高容错代码编辑、静态快速诊断与异步极速检索（`U3`, `U8`）

- **`apply_patch` 四级渐进模糊寻址**：支持精确匹配 → 行尾空白容错 → 首尾缩进无关寻址与自动缩进位移补偿 → Unicode 中英文标点/引号容错，大幅降低大模型补丁偏移重试率。
- **零执行毫秒级编辑后诊断**：`write` 与 `apply_patch` 写盘后自动完成 JSON 语法校验、JS/TS/CSS 括号与字符串配平扫描及 Git 冲突标记（`<<<<<<<`）检测，同轮直接反馈给模型自愈，不运行任何外部命令。
- **异步非阻塞检索引擎**：`grep` 优先走本机异步 `rg`（ripgrep）快路径，缺失时自动回退至带事件循环让出与 `.gitignore` 过滤的异步遍历器。

### 3. 执行循环韧性、两阶段压缩与有界子智能体（`U4`, `U5`, `U6`）

- **流式防卡死与截断自愈**：SSE 流内置 60 秒无事件看门狗、`Retry-After` 退避抖动；模型输出因 `max_tokens`（`finish === "length"`）截断工具参数时自动提示精简续写；连续 3 次相同工具报错触发死循环熔断器；连续只读工具支持最多 6 路并发调度并保持确定性顺序。
- **两阶段上下文压缩**：在调用摘要模型前优先执行零 LLM 开销的 Stage 1 微压缩（折叠早轮超长工具原始输出），并在 Stage 2 结构化压缩中锚定原始任务目标（`<pinned-task-anchor>`）与首尾预算保留。
- **有界子智能体 `delegate_task`**：支持 `explorer`（只读探索）、`verifier`（测试构建核验）与 `worker`（局部任务），严格继承父会话权限规则、禁止递归委派，降低主会话上下文噪声。

### 4. 仓库规范发现、动态 `@` 引用、对话分支与后台进程交互（`U2`, `U9`, `U10`, `U11`, `U12a`）

- **层级项目规范与 `/init`**：自动发现工作区层级中的 `AGENTS.override.md`、`AGENTS.md`、`.smalt/instructions.md` 与 `CLAUDE.md`（未信任仓库带显式边界声明）；桌面端 `/` 快捷指令菜单与 CLI 均支持 `/init`、`/compact`、`/fork`。
- **动态上下文引用**：输入框 `@` 菜单支持一键引用 `@git:diff`（未提交差异）、`@git:status`（分支与变更状态）与 `@terminal`（本对话最近进程/终端日志快照）。
- **对话分叉（Fork）与记忆建议**：侧边栏、消息气泡与顶栏均支持从任意节点分叉独立对话；对话中明确提出的项目开发约定可一键审阅保存为工作区记忆。
- **渐进式技能与交互式后台进程**：系统提示词仅注入轻量 `<available-skills>` 目录摘要，模型按需通过 `activate_skill` 读取正文与 `references/`；新增 `process_write` 支持向模型创建的后台进程写入标准输入（严格隔离用户手动终端）；Windows `ProcessSupervisor` 新增活动子进程上限防 fork 炸弹保护与 PowerShell 高危命令规则强化。

### 5. 任务执行失败累积与误报问题深度优化

针对日常智能体编程任务中容易出现“单次会话累积多条执行失败 / 仍有事项需处理”的深层问题，完成了五项底层根因治理：

- **Windows Git Bash 自动寻址与 POSIX 工具链注入**：修复 Windows 默认环境下 `where bash.exe` 仅命中系统未配置 WSL 空桩（`C:\Windows\System32\bash.exe`）而退回 `cmd.exe` 的问题。现在会自动通过 `where git.exe` 及常见 Git 安装目录定位 `<GitRoot>\bin\bash.exe`，并在子进程 `Path` 中补齐 `Git\bin` 与 `Git\usr\bin`，彻底消除智能体调用 `ls`、`grep`、`find`、`head`、`tail`、`bash -c` 时的命令缺失与 WSL 报错。
- **无匹配探测（`exit 1`）与前置目录切换（`cd &&`）精准评估**：
  - 修复 `findstr`、`grep`、`rg`、`where`、`which` 及带 `2>nul` 的存在性探路命令在“无匹配项”正常返回 `exit 1`（无错误输出）时被误判为“操作执行失败”的问题。
  - 排除 `--show-settings`、`--show-files`、`--help`、`--version` 等信息查询参数被误判为代码检查项。
  - 修复前置 `cd [/d] <dir> && <check>` 切换目录前缀被误判为 `shellStatusMasked`（“复合命令可能覆盖检查退出码”）的问题。
- **同轮自动恢复归并（`recoveredBy` 自动链路）**：无需依赖模型显式传入 `recoveryOf` 字段，当同一轮内满足以下任一恢复条件时，自动将前序失败折叠为“已改用其他工具 / 已有后续检查”，不再在底部失败面板中累积红字报错（同时严格保留“被拒绝操作 `blocked` 不自动消除”与“单测文件通过不掩盖全量测试失败”的安全边界）：
  - 早期探路命令失败后，同轮后续 `read` / `glob` / `grep` 或 `shell` 执行成功；
  - 带单文件过滤或参数错误的测试调用失败后，同轮后续更大范围的全量测试套件完整通过；
  - 同轮内对同一路径的 `apply_patch` / `write` 文件修改或 `read` / `glob` / `grep` 查找重试成功；
  - 同轮内重复执行 `ruff format --check`（如先查目录再查单文件 `--diff`）时自动合并重复发现项。
- **只读检查意图防污染**：修复挂载工作流技能（Skill）、记忆资料或文件引用时，系统拼接的模板文本污染 `taskIntent` 导致用户的只读检查指令（如“只做检查，不得修改”）被误判为代码修改任务、进而在发现格式问题时误报“仍有事项需处理”的问题。
- **流式工具调用分片乱序保护**：加固兼容接口流式返回中 `toolCallDelta` 先于 `toolCallStart` 到达时的参数缓冲保护，避免工具参数被置空导致校验失败。

## 安装与校验

### Windows x64

下载 **SmaltCode-Setup-0.0.8-SFox.exe**，使用 **SHA256SUMS.txt** 核对哈希（Windows 安装包未做商业代码签名，系统可能提示未验证发布者）：

```powershell
Get-FileHash .\SmaltCode-Setup-0.0.8-SFox.exe -Algorithm SHA256
# SHA256: f925e42e3c4c10536a819cf616ab967fd8a3696283fb7543e860bfa9e03db46e
```

### macOS 13+（Apple Silicon `arm64` / Intel `x64`）

可通过仓库 GitHub Actions 中的 `Package macOS Desktop (Manual)` 手动触发生成 **SmaltCode-0.0.8-macOS-arm64-adhoc.dmg** 与 **SmaltCode-0.0.8-macOS-x64-adhoc.dmg**（也可在 macOS 本地执行 `npm run package:desktop:mac:adhoc`）。拖入 `/Applications` 后，首次打开前如遇 Gatekeeper 提示，请在终端执行：

```sh
xattr -cr /Applications/SmaltCode.app
```
