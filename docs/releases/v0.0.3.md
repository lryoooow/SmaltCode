# SmaltCode v0.0.3 · 公开测试版

本次从 0.0.2 升级，集中改善长任务稳定性、模型选择、执行进度与资料处理。前期本地测试的技能库、文档工作台、异常恢复及执行验收一并纳入本版本。

**0.0.3 仍为公开测试版。欢迎大家试用、报告 Bug、分享使用场景和改进建议，也欢迎贡献代码与文档。**

## 更新内容

| 更新 | 使用体验 |
| --- | --- |
| 模型搜索与目录刷新 | 设置和输入框共用模型列表，可搜索名称、筛选服务商、刷新新型号，查看工具/图片能力及下线提示；保留自定义模型 ID |
| 按模型识别上下文容量 | 全面核对 OpenAI、Anthropic、DeepSeek、智谱、Kimi、通义、OpenRouter、Ollama 八类服务；读取接口元数据、官方规格或本地实际分配，标明来源，支持手动修正与恢复自动 |
| 上下文整理改进 | 修复长窗口模型套用统一小窗口导致的过早整理；换模型后在下一轮更新预算，区分总窗口、最大输入和最大输出，减少无进展的重复整理 |
| 单一任务进度与计划浮层 | 输入框上方只保留一个任务卡，展示真实动作、最近完成节点与计划入口；计划按需悬浮展开，详细执行记录继续折叠 |
| 明确的异常与验收结果 | 具体失败原因直接展示，可定位完整记录；格式/测试发现、执行错误、跳过或退出码冲突分别标注，避免“运行结束”被误判为验证通过 |
| 技能库与外部导入 | 内置常用技能，支持从 SKILL.md 文件、粘贴文本或公开 HTTPS/GitHub 文件链接导入；先预览、确认，默认停用，发送前主动选择 |
| 截图与文档工作台 | 支持粘贴/选择 PNG、JPEG；PDF 原页与翻页、Word 正文、Excel 工作表与单元格预览；文档选段可加入对话 |
| 用量、诊断与异常恢复 | 查看已记录的 Token 用量、上下文整理前后用量及待恢复任务；支持脱敏诊断导出，异常重开后提示检查再继续 |

## 可靠性与交互修复

- 运行中上翻历史、查看文件、切换对话、浏览技能或用量页，后台任务继续；刷新模型目录不覆盖用户已选型号。
- 历史计划独立于执行明细，停止或失败保留实际完成比例；修复同毫秒计划记录在重开后可能被覆盖的问题。
- Windows 命令可使用独立程序、参数和工作目录，保留真实退出码；补强缺失命令、超时、参数引用与退出码冲突处理。
- 后续复查只在范围一致且证据明确时关联旧操作；单个用例通过不清除整套测试失败，跳过不冒充验证通过。
- 无进展的上下文整理保留可诊断信息；界面用量与实际执行共用容量解析，运行中设置变更下轮生效。
- 补强路径、权限、附件、文档解析、网络导入与检查点冲突处理；解析工作线程隔离损坏文档，避免阻塞界面。
- 打包直接使用当前内核源码，验证安装包与构建文件一致，防止新界面携带旧内核；延续统一 S Fox 图标及托盘驻留。

## 下载与升级

1. 从本页 Assets 下载 **SmaltCode-Setup-0.0.3-SFox.exe**（Windows x64）。
2. 更新前通过托盘右键 **“退出 SmaltCode”** 完全退出旧版，再运行安装包并确认原安装目录。
3. 首次使用打开“设置 → 模型服务商”，保存服务连接，在模型菜单搜索或刷新型号。连接测试会发送简短推理请求，可能产生少量模型费用；单独刷新目录不发送对话正文或推理请求。
4. 同页提供 **SHA256SUMS.txt** 校验文件；界面、内核、EXE 与安装程序版本统一为 **0.0.3**。

```powershell
Get-FileHash .\SmaltCode-Setup-0.0.3-SFox.exe -Algorithm SHA256
```

安装包尚未签名，通过 Release 手动下载安装。升级无需清空用户目录中的 `.smalt` 配置和对话；应用层权限保护不等同于操作系统沙箱。

## 本地验证

- 类型检查与完整源码构建通过，**402 项自动化测试通过**；3 项需要 CLI SEA 可执行文件的检查跳过，本次发布的是桌面安装包。
- 实际打包桌面程序完成 **113 次模拟推理请求、5 次目录请求** 的界面验收；另完成技能、图片与文档流程 **7 次模拟推理请求**，均无渲染错误。
- 系统确认框由脚本在隔离测试进程中处理，应用授权检查保持不变；权限同意、拒绝与不可信页面分支由 IPC 单元测试覆盖。
- 安装产物的 **199 个构建文件** 与当前源码构建结果匹配，**186 个 worker/PDF 资源** 解包检查通过；产物实际解析 DOCX/XLSX/PDF、拒绝坏文件并恢复队列。
- 图标、产品名称、PE 数字版本、启动与内核连接检查通过；同一隔离配置连续 **3 轮托盘隐藏、恢复、退出和重开**，259 个运行文件保持不变。
- 验证均在本机执行，**GitHub Actions 保持关闭**。可查看 [版本验收记录](https://github.com/lryoooow/SmaltCode/blob/v0.0.3/docs/releases/v0.0.3-verification.json)。

## 当前边界

- 型号目录与容量来源可自动更新，但不保证所有账户、区域和代理路由均可用。未知容量标记“待确认”，可手动设置；已知下线或当前工具协议尚未适配的型号会说明原因。
- 默认约使用有效容量的 80% 时整理，并保留输出空间；小窗口模型、服务端限制与上下文估算仍可能影响触发时间。本版本未完成所有厂商真实推理及超长任务的逐一兼容认证。
- Word/Excel 为内容预览，PDF 支持原页绘制；暂不提供完整 Office 排版编辑、宏、公式重算或 OCR。文档选段用于对话引用，不用文本补丁覆盖二进制原件。
- 技能导入仅保存 SKILL.md，不自动执行配套脚本或安装插件依赖。网络导入拒绝私网及保留地址；代理 Fake-IP 可能导致下载被拒绝，可使用真实公网 DNS 或从文件导入。公开 GitHub 导入在本机网络下尚未完成成功验收。
- 检查点仅恢复受支持的文件编辑，不恢复终端、Git、数据库和网络副作用；异常恢复不会自动重放原操作。
- 当前提供 Windows x64；MCP、定时任务、长期记忆、目标模式和原生 Office 编辑仍属后续规划。
