# SmaltCode v0.0.5 · 工作区、远程开发与 Office · 公开测试版

本次将阶段 1–17 已完成的预览能力集中交付，同时修复 SSH、Office、多标签和退出清理中的可靠性问题。**0.0.5 仍是公开测试版**，欢迎报告 Bug、参与真实场景测试并提出设计建议。

## 工作区与交互

- 不选项目或目录即可对话；项目归类、资料来源、执行环境与产物分别管理，默认使用独立本地空间。
- 统一任务状态与节点进度、可展开计划、结果卡与直接失败原因；支持对话搜索定位、错误/上下文检查和待处理说明队列。
- 运行中可浏览历史、切换对话和查看文件；侧栏与浮层按内容分工，保留阅读位置。

## 执行、工具与协作

- 交互式终端、后台进程、多会话管理和项目常用操作。
- MCP 连接、工具发现、认证和插件管理；来源与权限可核对，外部内容隔离处理。
- 持续/定时任务、停止条件、记忆和任务模板；依赖应用驻留运行。
- 并行子任务、独立 worktree、结果汇总和合并审查，处理写入隔离、冲突与取消清理。

## 远程连接与容器

- SSH 主机、端口、**用户名和密码**有明确填写入口；支持私钥、本机 agent、指纹核验、SFTP 只读项目。
- 按对话授权 Linux 远程命令、交互式终端、进程监管、版本保护写入与回环端口转发；断线后不自动重放未确认操作。
- 设备配对、会话撤销、HTTPS 主机连接和手机查看/回答；共享范围明确，远程访问默认关闭。
- 本机 Linux 容器、受限 Dev Containers、配置/来源审查、手动生命周期节点、Features 和 SSH 容器目标。

## Office 与成果编辑

- 统一编辑会话、私有工作副本、保存确认、版本冲突检测和崩溃恢复。
- Writer 选段候选、修订与分页审阅；Calc 网格、真实公式重算、范围/结构/工作表与常用格式；Impress 幻灯片、对象、备注和已有布局/母版。
- 原生批注、受控批注迁移、引擎 PDF 预览/导出和可信 DOC/XLS 转换。
- 同一对话最多 8 个文档标签，独立草稿与版本；切换、关闭失败和重试保留其他文档内容。
- **LibreOffice 需自行准备并在软件中选择，不随安装包自动安装。** 复杂版式、图表、动画/音视频及任意文件保真尚未全部覆盖，复杂对象可交给原生编辑器处理。

## 重点修复

- 错误 SSH 密码导致旧凭据反复使用；无效替换密码回落到旧密码；取消后迟到的保存/选钥响应进入新表单。
- 兼容常见单密码 PAM 认证；验证码、多提示或多轮挑战不会自动收到登录密码。
- Office 关闭时最后落盘内容未收取、关闭中并发操作、退出确认超时后错误返回成功，以及恢复后清理标记残留。
- 退出期间禁止新文档与修改，同时允许最后草稿持久化；等待多窗口处理结果后判断是否退出。
- 安装后 Office 外部脚本和 SSH 解密线程使用真实解包路径；原生引擎不向安装运行目录写入 Python 缓存。

## 安装与升级

下载 `SmaltCode-Setup-0.0.5-SFox.exe`，使用 `SHA256SUMS.txt` 校验。升级前从托盘退出旧版，备份工作资料后按向导安装。应用、窗口、托盘、安装程序使用统一 S Fox 图标，版本资源同步为 0.0.5。

关闭主窗口仍会驻留托盘；右键托盘 **退出 SmaltCode** 才完全退出。密码通过 SSH 认证界面填写，不要放入对话。

## 验证与边界

全部验证在本地进行，GitHub Actions 保持关闭。既有全面回归与原生界面核对已通过，本次增加安装包的图标/版本、ASAR 文件、文档解析、真实 PTY/SSH 解密线程、Office 保存链、启动与托盘循环验收。具体结果和安装包摘要见 [发布验收记录](v0.0.5-verification.json)。
