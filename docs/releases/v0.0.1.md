# SmaltCode v0.0.1 · 首次公开测试版

> 这是历史版本。旧安装包及其校验附件已清理；请前往 [v0.0.2 公开测试版](https://github.com/lryoooow/SmaltCode/releases/tag/v0.0.2) 下载带狐狸图标的当前安装包。

SmaltCode 是多模型 AI 编程与办公桌面助手：围绕实际项目完成任务，将思考、执行、权限和文件产物放在一个清爽的工作区。

**0.0.1 是测试版本，功能和兼容性仍在打磨。欢迎大家踊跃试用，分享 Bug、交互感受和好的建议，也欢迎提交 Pull Request。**

## 本版本内容

- 全新中文 React 界面，连接实际 Electron / IPC / 智能体内核。
- 支持兼容 Chat Completions 与 Anthropic Messages 的模型服务，内置多个服务商配置与本机 Ollama 入口。
- 默认移除固定 50 步限制；支持停止、补充说明、流式文字与执行输出。
- 运行中调整权限；一次、本组与本对话同类审批；额外许可可撤销。
- 左侧项目分组、项目说明与工作文件夹；对话置顶、重命名、归档、恢复和删除。
- 思考、计划、命令与文件变更默认折叠；节点进展、实际文件预览和 diff。
- 运行中自由浏览历史、文件与其他对话，保留阅读位置，点击“查看最新”恢复跟随。
- 关闭窗口隐藏到系统托盘；托盘右键“退出 SmaltCode”完全退出。
- 统一 SmaltCode 名称和 Logo，修复输入框方形聚焦边框。

## 测试版已知边界

- 当前提供 Windows x64 安装包；macOS 和 Linux 桌面安装包尚未完成验收。
- 安装包暂未做代码签名，可能出现发布者未验证提示。
- 不同模型的工具调用、思考和上下文能力可能不同；请按服务商实际配置进行测试。
- 权限与路径保护属于应用层，命令以当前用户身份运行，不等同于操作系统沙箱。
- 无固定默认步数上限并不保证无限执行，任务仍可能因模型服务或上下文问题停止。
- MCP、技能、定时任务、目标模式和 Office 原生预览仍在规划；目前手动下载更新。
