# SmaltCode v0.0.4 · 数据容错与大历史优化 · 公开测试版

本次从 0.0.3 升级，集中修复代码审查中发现的项目数据容错、工具参数校验、模型能力校验和大历史性能问题，减少数据异常导致的断开、无效调用和浏览卡顿。

**0.0.4 仍为公开测试版。欢迎试用、报告 Bug、分享改进建议，也欢迎参与代码、测试和文档贡献。**

## 本次更新

| 更新 | 具体变化 |
| --- | --- |
| 项目数据容错与恢复提示 | 逐项校验项目，隔离坏记录并保留有效内容；主文件损坏时尝试有效备份，界面直接提示恢复情况，避免整页连接失败 |
| 保护恢复前的数据 | 单纯读取不会覆盖损坏文件；修复写入前保留带随机编号的原件副本，使用原子写入与有效备份；读取失败或检测到外部改动时停止覆盖 |
| 递归工具参数校验 | 检查嵌套必填项、数组元素、枚举、整数及大小边界，错误指向具体字段；拒绝非 JSON、循环或超限输入，Hook 改写后仍需校验 |
| 请求前检查模型能力 | 明确已下线、不支持当前工具协议或图片的型号在推理前给出原因；历史图片也参与校验，切换模型后更容易定位不兼容情况 |
| 大历史派生索引 | 通过文件标识、大小与时间验证元数据索引，失效或损坏时重建；从日志尾部有界读取完整行，减少重复全量加载，已完成任务不在启动时全量重放 |
| 大历史浏览与流式输出 | 批量初始化对话列表，时间线和执行明细分批展示；加载更早记录保留阅读锚点，切换对话保留展开范围；超长回复流式输出先用纯文本，结束后恢复 Markdown |

时间线默认展示最近 **60** 条记录，展开执行详情先展示最近 **80** 项，均可继续加载。分页只影响界面展示，**不会删减原始对话或模型上下文**。运行中仍可浏览、查看文件、切换对话和隐藏到托盘，延续单一任务进度与计划浮层。

参数限制包含计划最多 200 步、问题选项最多 30 项及递归输入资源上限；明确的参数错误在执行前返回，不会直接交给工具运行。工具仍遵守现有审批、工作区与拒绝规则。

## 下载与升级

1. 从本页 Assets 下载 **SmaltCode-Setup-0.0.4-SFox.exe**，适用于 Windows x64。
2. 通过托盘右键 **“退出 SmaltCode”** 完全退出旧版，再运行安装包，确认原安装目录。
3. 升级无需清空用户目录中的 `.smalt` 配置、项目和对话。若出现项目恢复提示，请检查恢复后的项目说明；备份可能早于最后一次编辑。
4. 界面、内核、EXE 和安装程序版本统一为 **0.0.4**，沿用统一 S Fox 狐狸 Logo。同页提供 **SHA256SUMS.txt** 校验文件。

```powershell
Get-FileHash .\SmaltCode-Setup-0.0.4-SFox.exe -Algorithm SHA256
```

安装包尚未签名，目前通过 Release 手动下载更新。

## 使用边界

- 项目容错无法恢复从未保存的数据；备份可能较旧，写入保护提示出现时请先检查文件和其他运行实例。
- 模型能力检查依赖已知规格和接口元数据。未知能力保留兼容，第三方网关、账户和路由仍可能有不同限制；模拟验收不代表所有厂商真实推理均通过。
- 派生索引可以重建，原始 JSONL 仍是对话记录。当前分页改善展示开销，打开单个对话和组织模型上下文仍需读取其必要历史，不宣称无限历史始终无开销。
- Word/Excel 为内容预览，PDF 支持原页绘制，暂不提供完整 Office 编辑或 OCR；技能导入仅保存 SKILL.md。公开 GitHub 网络导入在本机网络条件下仍未完成成功验收，可先从文件导入。
- 应用层权限保护不等同于操作系统沙箱。检查点不恢复终端、数据库或网络副作用，异常恢复不会自动重放命令。
- 本次提供 Windows x64；其他桌面平台及 MCP、定时任务、长期记忆等规划能力未在此版本新增。
