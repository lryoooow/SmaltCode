# SmaltCode v0.0.2 · 公开测试版

本次从 0.0.1 升级，集中完善后台任务、文件预览与修改体验，并启用统一的 S Fox 狐狸 Logo。

**0.0.2 仍是公开测试版。欢迎大家踊跃参与，报告 Bug、提出交互与功能建议，也欢迎提交代码和文档改进。**

## 本次新增

| 功能 | 使用体验 |
| --- | --- |
| 任务中心与桌面通知 | 左侧集中查看运行、待处理、未读、失败和已完成任务；可搜索、停止、标为已读并返回对应对话。完成、失败或需要审批/回答时可收到通知。 |
| 多标签文本预览 | 同时打开多个产物文件，各标签独立切换、关闭、刷新并保留阅读位置。 |
| 文本选区修改 | 在预览中选中文本并加入当前对话，填写修改要求后发送；发送前校验文件，过期选区会要求重新选择。 |
| @ 文件引用 | 搜索工作区文件，用键盘或鼠标选择资料；引用草稿按对话独立保存，选择资料不会提前发送消息。 |
| 变更审查与检查点 | 查看实际文件差异，撤销单个文件或某次文件操作；检测后续/手动修改冲突，保留对话历史。 |

## 交互与显示改进

- 运行中可以上翻历史、浏览文件、切换标签和其他对话；新输出与完成事件不会强制拉回当前任务。
- 对话仅显示原始提问与简洁引用标记，避免内部上下文数据和长摘要撑坏页面。
- 后台文件更新时提示刷新，保留当前阅读位置；各对话的引用、标签与阅读状态相互独立。
- 通知不会主动抢焦点，已处理请求会取消提醒；点击后才恢复窗口并定位对话。
- 浅色、深色及较窄窗口布局保持统一；关闭窗口继续隐藏到托盘。

## 新 Logo 与安装包整理

- 狐狸侧脸、身体与尾部融入字母 S，配合 SmaltCode 字标，保留品牌蓝。
- 首页、侧栏、窗口、托盘、通知、应用 EXE 与安装程序使用同一矢量母版。
- 核对全部图标组与 16～256 像素资源，并验证 Windows 实际读取的安装包文件图标。
- 安装包统一为 **SmaltCode-Setup-0.0.2-SFox.exe**，避免与早期同名候选包混淆。
- 清理旧安装包、重复副本与过期构建输出；0.0.1 页面和版本标签保留历史记录，旧下载附件下架。

## 下载与安装

1. 从下方 Assets 下载 **SmaltCode-Setup-0.0.2-SFox.exe**（Windows x64）。
2. 可用 **SHA256SUMS.txt** 核对文件。应用和安装程序内部版本均为 **0.0.2**。
3. 按向导安装；首次使用在设置中配置服务地址、模型 ID 与密钥，测试连接后选择工作文件夹。

安装包尚未签名。目前通过 Release 手动下载更新；对话、项目和真实工作文件不会因本次构建产物清理而删除。

## 测试与边界

- 类型检查、完整源码构建通过；24 个文件共 **202 项自动化测试通过**。
- 实际打包程序完整界面回归：**105 次本地模拟模型请求，零渲染错误**。
- 应用与安装程序图标、产品标识、数字版本、启动、托盘隐藏/恢复/退出检查通过。
- 当前验证面向 Windows x64；本地模拟服务覆盖真实 Electron / IPC / 内核链路，不代表已验证所有第三方模型或其他桌面平台。
- 文件引用支持工作区内的 UTF-8 文本，每次最多 10 项；完整文件每项最多取前 24000 字符，过期选区会拒绝发送。
- 检查点仅覆盖 write / apply_patch 文件编辑，按操作保存；不恢复终端、Git 状态、数据库或网络副作用。恢复前需停止同工作区任务，存在后续修改时不覆盖。
- MCP、技能、定时任务及 Office 原生预览仍在规划，本次第 2 项先交付多标签文本预览与选区修改。
